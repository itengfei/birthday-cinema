# 🎬 Birthday Private Cinema

一个为女朋友用心打造的生日网页礼物——用 14 幕"电影"讲述我们的故事。

在线预览：[birthday-cinema.vercel.app](https://birthday-cinema.vercel.app)

## ✨ 体验

这不是一张普通的生日贺卡，而是一场**私人放映**。用户会依次经历：

- 🎟️ **入场券** — 一张精美的电影票，座位是"我旁边"
- 🔑 **秘密暗号** — 解锁答案藏在我们第一次见面的细节里
- 📖 **6 个回忆章节** — 从空手见病人、土豆丝晚餐、没看完的电影，到雪地吵架和日常小破梗
- 🎞️ **互动选片** — 选 3 幕放进"今晚片单"
- ⭐ **点亮五颗星** — 每一颗星对应一句真心话
- 🔮 **未来票根** — 给未来留四张票：结束异地、订婚结婚、一起过日子、环游世界
- 💌 **终章信** — 一封完整的生日情书

## 🛠️ 技术栈

纯静态页面，零依赖，开箱即用：

- HTML + CSS + Vanilla JavaScript
- CSS 自定义属性 (`--ink`, `--gold`, `--blush` 等影院配色)
- 玻璃拟态 + 渐变 + 噪点纹理背景
- 响应式设计，移动端优先
- CSS 动画（滚动字幕、浮动星星）
